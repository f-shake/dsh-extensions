# ASR 误听的机理与模式（通用）

> `SKILL.md` §4 的展开。**不含任何个人专名**，换个人、换领域照样能用；
> 具体词条一律在 `personal/glossary.md`。

## 一、错在哪一层

ASR 由声学模型 + 语言模型拼成，错也分两层：

| 层 | 出错原因 | 长相 |
|---|---|---|
| 声学 | 同音 / 近音、口音（前后鼻音、平翘舌、n/l、h/f、儿化）、连读吞字、语速快 | 字都被换掉，但读起来一样 |
| 语言模型 | 专名是「未登录词」→ 硬拆成读音相近的常用词；标点与断句几乎不生成 | 出现一串莫名其妙但语法通顺的常用词 |
| 解码后处理 | 拼音输入法的联想、热词偏置 | 用词突然「网感」或串到别的领域 |

由此得出一条实用推论：**普通词反而错得少，成片错的地方多半是专名**。所以先攻专名，收益最大。

## 二、可识别模式（七种主模式 + 断句）

### 1. 同音替换
读音完全一致、字被换成更常见的那个。
- 信号：句子通顺但语义别扭；换成另一个同音字立刻合理。
- 例（虚构）：`王主任` 被写成 `汪主任`；`接口` 被写成 `借口`。
- 处置：结合领域常识 + 词表；改完全文统一。

### 2. 近音 / 方言
读音接近、声母或韵母差一点。
- 信号：本地口音里的 n/l、h/f、平翘舌、前后鼻音；普通话里不存在的搭配。
- 例（虚构）：`规划院` → `规划员`；`滨湖路` → `宾湖路`。
- 处置：**高风险**。宁可保留并问，也不要「听着像」就改。

### 3. 连读吞字
语速快时音节粘连，ASR 补字或吞字。
- 信号：句子里少一个字、多一个字，读起来还通；或两个词粘成一个。
- 例（虚构）：`差点把杯子碰倒` → `差点杯子碰倒`；`附近` → `府近`。
- 处置：按语法补/删一个字，不改语序。

### 4. 专名未登录（OOV）
人名、单位、产品、地名不在词表里，被拆成读音相近的常用词组合。
- 信号：出现「常用词 + 常用词」的怪搭配，且该位置本该是个名字。
- 例（虚构）：人名「云舒」被写成「云书」；品牌名被拆成读音相近的常用词。
- 处置：这类**必须靠个人词表兜底**；没有词表就一律列入待确认。

### 5. 数字与单位
- 信号：中文数字与阿拉伯数字混用；「块 6」「一百六」这类口语数字；单位被读成汉字（`KM每H`）。
- 处置：统一写法（`160km/h`、`57`）；口语数字按上下文换算，换算不了的标存疑。
- **金额、日期、账号、型号不改**，只标存疑——这类错一个字代价太大。

### 6. 英文 / 缩写
- 信号：英文按读音转成汉字；大小写全丢（`wifi`、`iphone`）；缩写少字母。
- 处置：官方大小写优先；没有官方写法的，按用户历史写法统一（词表里有「产品统一写法」节）。

### 7. 改口与重复
说话人自己改口，ASR 把两遍都留下。
- 信号：同一句出现两次、后一次带修正词（「不是，我是说……」）；连续重复字。
- 处置：留后一遍、删前一遍；**只删重复，不合并两句不同的意思**。

### 8.（附带）断句缺失
ASR 基本不生成标点，长句一逗到底。
- 信号：一句话跨了好几个意思；主谓宾错位。
- 处置：按语义断句、按场景分段（按场景比按时间流水更好读）。断句时**不增删词**。

## 三、处理优先级

```
专名（人名 > 单位 > 产品 > 地名）
  > 语义硬错（同音、漏字、数字）
    > 通顺（语序、断句）
      > 格式（空格、标点）
```

前一层没做完不要跳到下一层——专名不定，后面的通顺化可能白做。

## 四、长稿策略

1. **先扫后改**：`glossary-scan.ps1` 拿到候选清单，再通读定夺。
2. **建全局映射表**：处理每一块时把「误听 → 正确」记下来，跨块复用。
3. **按场景分块**（一天、一场会、一段行程），不按字数硬切；块边界落在段落上。
4. **收尾做残留扫描**：错误写法是否还在？正确写法有没有被下一块又改回去？
5. 块与块之间**不重复改写**同一句；最后通读一遍连贯性。

## 五、反模式（别做）

- ❌ 按「标准普通话」改写方言口语——「咋回事」「整」「弄」不是错。
- ❌ 用方位、距离、上下文「合理推测」替换不确定的地名（真实教训：按方位把一座真实存在的山改成了另一座）。
- ❌ 把「听上去顺」当成「听对了」——ASR 的错误常常读起来很顺。
- ❌ 一次改一大片，却不说明依据。
- ❌ 把词表当正则表达式机械替换——同一个读音在不同语境下可能是对的（既是人名，也可能真是动词）。
