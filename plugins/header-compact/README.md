# 标题行收紧（header-compact）

手机窄屏下，把会话标题行里最占地方的两处收紧：子智能体与后台任务的计数按钮换短写法，桌面端的「在本地打开」整组隐藏。

## 它解决什么

标题行是一条不许换行的 flex 行：右侧的计数按钮、更多菜单和「在本地打开」都是固定宽度，会话标题只能吃剩下的空间。手机上同时开着子智能体和后台任务时，两个按钮的文案（「3 个子智能体」「1 个后台任务」）加上「在本地打开」，会把标题挤没；而「在本地打开」在手机上本来也点不开电脑的文件管理器。

装上本插件后，视口宽度 ≤ 767.98px 时：

- 子智能体按钮：`3 个子智能体` → `智能体 3`
- 后台任务按钮：`1 个后台任务` / `1 个后台任务运行中` → `后台 1`
- 「在本地打开 / 显示文件位置」整组按钮连同下拉箭头隐藏

按钮的点击与弹层行为完全不变，只换文案、隐藏一个手机端用不上的入口。视口回到 767.98px 以上（旋转、窗口放大）时逐字还原。

## 边界

- 只认「数量 + 个 + 子智能体 / 后台任务」这一种形状（英文认 `subagent` / `background job`）。上游换了措辞或语言就**原样不动**——宁可少改，也不改坏不相干的文字。
- 可见文案丢掉「运行中 / 正在运行」后缀（运行状态由按钮上的状态点表示），`aria-label` 仍保留后缀。
- 只隐藏**会话标题行**里的「在本地打开」；右侧文件面板里的同款按钮照常保留。
- 只改文本节点的值，不替换节点、不动 DOM 结构，React 之后重渲染照常工作。
- 与 `mobile-fit` 无耦合：那个管外壳与抽屉，这个只管标题行文案与那一个按钮，各自独立装卸。

## 安装

```powershell
node C:\Running\dsh\node_modules\@deepseek-ai\dsh\lib\bin.js plugin --profile aa add `
  "@local/header-compact@link:<repo>/plugins/header-compact"
```

`<repo>` 指本仓库的绝对路径（安装时换成自己机器上的位置）。

CLI 会同时写入 profile 的依赖与 `dsh.profile.bundles`；**改完 profile 要重启 dsh**（客户端清单在启动时扫描），然后手机硬刷新。之后只改 `client.js` 不必再重启，硬刷新即可（包地址带按 mtime 派生的 `?rev=`）。

## 卸载

从 profile 的 `dsh.profile.bundles` 移除 `@local/header-compact` 并删掉依赖，重启 dsh。插件被卸载时会断开观察器、摘掉样式表、把文案还原。

## 验证

```powershell
cd plugins\header-compact
node --test test/
```

手动验收：手机竖屏看两个按钮是否变成「智能体 3」「后台 1」、标题行右侧的打开按钮是否消失；手机横屏与桌面宽屏看文案与按钮是否恢复原样。

## 实现要点

- 判定用 `matchMedia('(max-width: 767.98px)')`，跨阈值时收紧或还原。
- 标题行由宿主渲染、计数还会变，所以用 `MutationObserver` 盯 DOM，每帧最多扫一遍；自己写回的长文案会被再次收紧，循环在没有改动时自然停下。
- 改写前把原值登记进 Map，离开窄屏逐字写回，不靠反向猜文案。
- 隐藏按钮是纯 CSS：用 `:has()` 把作用域锁在「含 `[data-conversation-header-corner]` 的标题行」里。
