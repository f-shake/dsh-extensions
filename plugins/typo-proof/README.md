# typo-proof

日记错别字检查：逐句交给本地小模型采样三次，三次里有两次改动了这句，就把这些改动（含只出现过
一次的位置）交给云端盲复核；确认的改动写进 `docx` 副本的 Word 修订模式，原文件不动。

**当前状态：后端、docx、模型调用、面板与设置都已完成，单测 83 条。没有演示模式——
调不通模型就报错，不会拿假数据充数。**

## 怎么用

对话里：

```
typo_check({ file: "<docx 的绝对路径>" })
```

右侧栏「错别字」面板：点「开始检查」走同一套管线，进度、候选、下载都在面板里。

两种入口共用一份任务状态，同一时间只跑一个——两个任务抢同一个本地模型只会更慢。

## 跑真的：配置

**两处入口，优先级：面板里存的设置 > `cordis.patch.yml` > 默认值。**

### 面板里改（推荐，改完立刻生效，不用重启）

要检查的文件**不在设置里**：它是每次运行的输入，放在面板空态的那个输入框里，
直接填绝对路径、点「开始检查」。设置里只有「配一次管很久」的东西。

右侧栏「错别字」面板右上角的**「设置」**：采样 provider / 采样模型、复核 provider / 复核模型、
最小汉字数、采样次数、并发。provider 与模型都是**下拉**——选项来自模型栏
（`llm.listProviders()` + `llm.listModels(provider)`），不用手打。换 provider 时模型会自动
切到该 provider 的第一个，避免留下一个不存在的组合。

保存后存在 `~/.dsh/typo-proof/settings.json`（本机用户目录，不在仓库里）。服务端每次请求都重读
一遍，所以点完保存再点「开始检查」用的就是新值。

### `cordis.patch.yml` 里改（改的是默认值，要重启）

| 键 | 说明 |
|---|---|
| `file` | 要检查的 docx；工具调用时传 `file` 可以覆盖 |
| `localProvider` / `localModel` | 本地小模型。模型名必须和模型栏里注册的一致 |
| `reviewProvider` / `reviewModel` | 云端复核模型 |
| `minHanzi` | 句子里少于这么多汉字就不检，默认 8 |
| `samples` | 每句采样几次，默认 3 |
| `concurrency` | 本地采样并发，默认 3；4B 模型在本机开 3 路比较稳 |

模型名对不上时不会闷着失败：点「开始检查」会直接报错，并把模型栏里现成的 provider / 模型列出来。

## 一次检查做什么

```
读 docx → 切句 → 每句采样 3 次 → 三次里有两次改动了这句 → 改动并集送盲复核 → 写副本 → 报告
```

- **只认单字替换**：删一个字补一个汉字才算候选；整词改写、增删短语都当「模型在改写」作废。
- **两票闸在句上，不在字上**：三次里至少两次改动了这句才算可疑；进复核的是这些采样的**改动并集**，
  所以同一句里只被改过一次的位置也会送复核——漏检的代价比多跑几次云端更大。
- **相似度闸**：一次采样改太多（整句相似度 < 0.80 或改动超过 5 处）就作废那一次。
- **盲复核**：不给候选，让云端模型自己改一遍再比。直接问「A 改成 B 对不对」，它会顺着说对。
- **只写副本**：`<原名>_校对副本_<yyyyMMdd-HHmm>.docx`，原文件一个字节都不动（单测里用 sha256 断言过）。
- **修订形态**：`w:del`（原字）+ `w:ins`（新字），作者 `typo-proof`，复用原 run 的 `w:rPr`。

## 产出物

| 文件 | 内容 |
|---|---|
| `…_校对副本_….docx` | 带 Word 修订的副本，Word 里「审阅 → 接受全部修订」即完成 |
| `…_校对报告_….json` | 全部候选、复核结论、跳过项、耗时 |
| `…_校对候选_….csv` | 段号 / 句序 / 原字 / 新字 / 投票数 / 复核结论 / 上下文（带 BOM，Excel 直接开） |

## 部署与访问控制

**`/typo-proof` 这三条路由不自己做登录校验**，和仓库里 `deliver` / `git-panel` 一样，
依赖反代把整个站挡在鉴权之后（例如 nginx 的 `auth_request`）。插件里只做了一层**同源校验**：
拒绝 `sec-fetch-site: cross-site`、以及 `Origin` 与 `Host` 不一致的请求，用来挡「别的站点的
页面借用户浏览器打过来」这一类 CSRF。

**如果你的 dsh 暴露在公网，必须确认反代也保护 `/typo-proof`**：`/status` 会返回日记的绝对路径
与候选原句，`/download` 与 `/csv` 直接给整份文档和候选清单。只监听 loopback 时无此问题。

## 代码结构

| 文件 | 负责 |
|---|---|
| `index.js` | 工具注册、任务状态、`/typo-proof` 三条路由、配置归一化 |
| `lib/zip.js` | zip 读写（`node:zlib`，无第三方依赖） |
| `lib/xml.js` | 标签扫描、属性原样取值、文本提取、转义 |
| `lib/docx-read.js` | `document.xml` → 段落 / run / 偏移；标出表格、TOC、超链接、既有修订 |
| `lib/segment.js` | 切句、`##…##` 加密段、跳过规则、前后句上下文 |
| `lib/diff.js` | LCS 比较，取出单字替换与相似度 |
| `lib/candidates.js` | 三次投票、编辑过滤、输出清洗 |
| `lib/prompts.js` | 采样与复核提示词（版本号进缓存键） |
| `lib/pipeline.js` | 编排、并发、缓存、进度、写盘 |
| `lib/cache.js` | 句级缓存（键 = 模型 + 提示词版本 + 句子） |
| `lib/docx-write.js` | 按位置切 run、生成 `w:ins` / `w:del`、写副本 |
| `client.js` | 面板与工具卡片 |

## 边界与已知限制

- **只做单文件**。目录批量留到 v2。
- **不可写的段落会跳过并记账**：表格里的、已有修订的、run 里带制表符/域代码/图片的、
  超链接里的字。跳过的条目写进报告 `writeSkipped`。
- **中文单字**才算候选：英文、数字、标点、繁简转换都不算。
- **复核外发**：云端复核会把「前一句 + 本句 + 后一句」发出去，不脱敏（Q6 已定）。
- **缓存**在 docx 同目录的 `.typo-proof-cache/`，删掉即可重算。

## 面板结构

右侧栏一个标签页，标题「错别字」。空态 / 运行态 / 结果态 / 错误态四种；候选折叠时就看得到
句子（长句按改动点开窗），展开补前后句与三次采样；否决项不给删除线，只把被点名的字标虚线，
因为否决的意思是原文不动。
