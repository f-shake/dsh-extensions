# @local/deliver

把宿主上的文件变成**当前浏览器里能点开下载的一组条**，再给一个「投递箱」把最近的投递都找得回来。

远程用 dsh 时，宿主上产出的报告、导出数据、截图、安装包都在那台机器上：`present` 只能预览或在**宿主桌面**打开，会话日志导出只管日志。这个插件补的就是这一段——不离开 dsh、不需要另起投递服务、也不需要上传到别处。

## 用法

模型调 `deliver` 工具，**回合末尾**出现一组单行条，一行一个文件：

```
周报 2026-11.pdf    2.1 MB · 还有 11 小时   [预览] [下载]
build-output.zip    184 MB · 还有 11 小时   [下载]
```

工具行本身不画卡片。早先工具行一张整卡、回合末尾再来一条摘要，同一批文件会在正文里
上下出现两遍；现在只留这一组。

- 这组条在**回合结束后**才出现：平台只给已结束的回合挂这个槽位。回合跑得久时，文件要等收尾才看得到。
- 右侧是「预览」「下载」；没有绝对路径的老记录不给预览——按了也打不开。
- 点「下载」：先 `HEAD` 确认还能下，再整页导航到下载地址。桌面浏览器停在原页面，Android 客户端会转给系统的下载管理器（它已经带上了 WebView 的 cookie）。
- 点「预览」：同样先 `HEAD` 确认还有效，再交给右侧栏的**内置文档预览**（`dsh-resource://file/session/<会话>/<绝对路径>`），Markdown、代码、图片、PDF、Office 都由它渲染；不支持的后缀它自己会说明。文件已过期或已撤销时不打开，只在行尾提示「已失效」。
- 「撤销」移到右侧栏的投递箱里（每条投递一个）；投递箱从右侧栏自己的入口打开。
- 一个文件都没投成时不会有条出现，工具行里会留一行失败原因。
- 宿主重启、记录过期或被撤销后，这一轮的投递会退回工具行：同样的一行行，标「已失效」，不会整轮消失。

## 预览

- 预览走内置预览，所以投递的文件**不需要**在工作区里：地址带的是宿主上的绝对路径。
- 内置预览直接读磁盘、绕开投递表，所以点之前必须先 `HEAD` 一次——否则撤销过的文件还能被打开，和下载按钮的「已失效」自相矛盾。
- 同一文件重复点「预览」不会叠加页签（地址就是内容身份）；不同文件各占一个。
- 宿主把每个文件的 `absPath` 与会话 id 一起给客户端（工具输出与 `/deliver/list` 都带），客户端据此拼地址，不自己猜路径。


## 工具

`deliver({ files: [{ path, name? }] })`

- `path` 可以是绝对路径，也可以相对会话工作目录。
- `name` 覆盖下载时显示的文件名（默认取原文件名）。
- 一次最多 20 个文件（`maxFiles`）。
- 单个文件失败（不存在、是目录、超过上限）不牵连其余文件，失败原因会写进工具结果。
- 一个都没成功时工具直接报错，把每个原因带上。

## 路由

全部挂在 `/deliver` 前缀下，走 dsh 自己的登录态；**不需要改 nginx**。

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` / `HEAD` | `/deliver/<id>/<n>` | 下载第 n 个文件；支持 `Range`（206 / 416） |
| `GET` / `HEAD` | `/deliver/list` | 投递箱数据：`{ ok, now, deliveries }`；`?session=<id>` 只列该会话的投递（回合末尾那组条用它筛） |
| `DELETE` | `/deliver/<id>` | 撤销；重复撤销幂等 |

失效、撤销、源文件被删都会返回一张中文说明页（404 / 410），不是 JSON——用户是在手机浏览器里点开它的。

## 配置

`cordis.patch.yml` 的 `config`，都有缺省值：

| 字段 | 默认 | 说明 |
|---|---|---|
| `ttlMinutes` | `720` | 投递有效期（12 小时） |
| `maxFileBytes` | `4294967296` | 单文件上限（4 GiB） |
| `maxFiles` | `20` | 一次投递的文件数上限 |
| `maxDeliveries` | `200` | 内存里最多保留多少条，满了丢最旧的 |

## 安装

```powershell
node C:\Running\dsh\node_modules\@deepseek-ai\dsh\lib\bin.js plugin --profile aa add "@local/deliver@link:<repo>/plugins/deliver"
```

再在 profile 的 `dsh.profile.bundles` 里加上 `@local/deliver`，重启 dsh 生效。

## 边界

- **不做免登录直链**：那要在 nginx 上放行一条绕过 `auth_request` 的路径，等于把宿主文件对公网敞开。站内地址已经覆盖「远程自己下」。
- **不复制快照**：下载时读原文件。文件后来被改，下到的就是新内容；被删则 404。
- **不落盘**：投递表在宿主内存里，重启后内存清空，旧链接返回 404（「这条投递不存在」）。正文里那组条照着列表画，列表里没有的就退回工具结果里的 meta、显示为「已失效」；投递箱则同样变空。
- **不是文件服务器**：URL 只认投递时分配的随机 id，不接受任何路径参数。
- **目录不投递**：请模型先打包成文件。

## 过期与重启的区别

| 情况 | 状态码 | 说明页 |
|---|---|---|
| 超过有效期 | 410 | 这条投递已过期 |
| 被撤销 | 410 | 这条投递已撤销 |
| dsh 重启过 | 404 | 这条投递不存在 |
| 源文件被删 | 404 | 源文件已删除 |
